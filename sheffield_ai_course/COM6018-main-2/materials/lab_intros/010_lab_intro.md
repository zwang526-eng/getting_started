## Running the notebook

Once you have downloaded the .ipynb file, you can run it on your own machine.

```bash
jupyter notebook 010_python_intro.ipynb
```

Alternatively, if you have installed VS Code, you can open the notebook in VS Code and use the VS Code Jupyter extension.

```bash
code 010_python_intro.ipynb
```
